# Preserved upstream sources

These are unchanged text sources recovered from three SOLOBOLO packages and
the supplied RH_FIVE_INDUCTION package. Their manifests and reports describe
historical work; they are not certificates for the new repository.

`provenance/input-files.json` records hashes of all 27 supplied inputs and
the three recovered SOLOBOLO archives. `provenance/upstream-files.json`
records hashes of preserved text files. Executables, object caches, copied
third-party Mathlib trees and historical runners are excluded.

Only modules in the root build manifests participate in the current build.
The full mathematical audit explains which inherited statements still assume
actual-data calibration, a universal successor, or radius exhaustion.

Short directory names keep Windows extraction paths manageable. The original
archive names and unchanged file hashes remain in the provenance manifests.
