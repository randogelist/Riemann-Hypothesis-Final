# Recovered equivalence source bodies

The `.lean` filenames are their original bytes' SHA-256 digests. They are
archival source bodies, not runnable module paths. Original snapshot/module
paths, cited line numbers, hashes and applicable supplied license notices are
mapped in `RH-Equivalences/source-map.json` at the repository root.

This selection preserves every primary, alias, supporting-result and
definition source reference in the historical catalogue. It is not the full
dependency closure for every snapshot. Some preserved model sources contain
explicit research axioms and opaque objects. Nothing in this directory is
imported by the active build plans.

Original source headers and supplied notices are preserved. No new authorship
or blanket license grant is asserted for the assembled collection.
